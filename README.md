# 注意

由于众所周知的原因，目前SnowLuma和NapCat皆处于不可用状态，因此除非你有备用的连接方式，以及自己开发的意愿，否则本项目也是基本不可用的。本项目并未完全开发完成，部分功能并不可用或者并不实用，在有下一个提供WebSocket连接的OneBot框架项目出现之前，本项目暂停开发迭代。

## 目前的局限性

- 本项目接取QQ信息的两个方式，SnowLuma 和 NapCat，两者的仓库皆已处于不可见状态。
- 项目内提示词仍有很大优化空间，聊天记录分析有时会出现摘要回传超出限制等其他问题导致失败。
- 每个对象的档案中并没有聊天总览，聊天分为私聊和各个群聊单独进行分析。
- 情绪和态度变化图表仍未完善，且情绪和态度变化判断仍待优化。
- 其他一些可能导致不便或者功能运行不正常的因素。 

# ChatAnalyzer · 对话观察室

ChatAnalyzer 是一款供个人在局域网中使用的对话分析工具。它将 QQ 聊天、对象档案和重要记忆整理在同一个网页里，帮助你回顾交流、留意关系中的变化，并在需要时获得沟通建议。

日常聊天往往零散而密集：一次随口提到的喜好、一个尚未兑现的约定，或是一段语气发生变化的对话，都可能被新的消息淹没。ChatAnalyzer 会结合近期交流与过往记忆，为你提供理解这些线索的参考。

## 围绕每个人整理交流

你可以为关注的人建立独立档案，记录称呼、标签、关系简介、喜好、边界和沟通习惯，也可以填写自己的档案，让分析更了解双方的背景。

每个对象都有对应的会话工作区，集中查看私聊及指定共同群中的交流。淡蓝与粉蓝的界面将档案、对话和分析放在一起，方便在阅读消息时对照背景。

## 看见变化，也看见依据

ChatAnalyzer 会结合对话内容，观察对方表达出的态度与情绪变化，并展示判断原因和近期趋势。文字之外，也支持分析聊天图片及图片形式的表情包，让图文交织的交流保留更多上下文。

这些结果是 AI 根据有限线索作出的推测。分数与趋势用于辅助回顾，不能代表对方真实的心理状态；理解一段关系仍需要你的经验与直接沟通。

## 留下值得记住的事

对象的长期画像与带有时间、消息来源的事件记忆分别保存：前者帮助了解这个人，后者帮助回想发生过什么。重要生活节点、待履行的约定，以及对后续相处有持续影响的变化，都是记忆整理关注的内容。

你可以查看记忆依据，也可以手动修订画像。AI 会随交流继续更新资料，记忆整理侧重重要变化，尽量排除普通闲聊与无关群消息；自动筛选仍可能有误，需要你核对。

## 在需要时提供建议

应用会先整理近期交流，再判断是否值得给出建议；需要时，结合相关历史记忆生成更具体的沟通参考。没有必要建议时，也会说明原因。

你可以调整分析频率，或暂停某个对象、某段会话的 AI 分析。暂停期间仍继续接收消息，恢复后可处理积压内容。

## 保持你原本的聊天方式

ChatAnalyzer 通过独立运行的 SnowLuma 或 NapCat 接入 QQ，读取双方私聊及指定群的消息。首次连接时可导入桥接服务当前能够读取的历史，断线重连后会尝试补齐缺失记录；实际范围取决于桥接服务，不能保证恢复完整聊天历史。

你仍在原 QQ 客户端中登录和聊天。ChatAnalyzer 只读消息，不代发回复，不撤回消息，不标记已读，也不管理 QQ 登录状态。目前支持 QQ，微信接入尚未实现。

## 开始使用前

你需要一个运行 ChatAnalyzer 的主机、已接入 QQ 的 SnowLuma 或 NapCat，以及支持图片输入与 JSON 输出的 OpenAI 兼容 AI 服务。应用提供 Docker Compose 部署方式，通过浏览器访问，适合个人在局域网中使用。

首次运行时使用'docker compose up -d --build'进行部署，随后可通过'主机IP:7456'进行访问。

开始使用后，先在“连接设置”中配置 QQ 桥接与 AI 服务，再填写自己的档案、为对象建档，并按需指定共同群，即可逐步积累对话与记忆。AI 调用费用由你选择的服务决定。

聊天记录、档案和记忆保存在部署主机上，AI Key 与桥接 Token 加密保存。分析时，相关聊天内容、图片及记忆会发送到你配置的 AI 服务，因此使用前应了解该服务的数据处理方式。聊天资料本身并未加密存储，请妥善保护主机与备份。
